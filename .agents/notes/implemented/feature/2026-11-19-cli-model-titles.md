# CLI 空标题聊天的模型命名

Status: implemented

## 原因与行为

可选名称实现只省略创建阶段的人工 `thread/name/set`，并监听名称更新。Codex 0.164 原生自动命名由 TUI 在首条用户消息确认后发起临时模型请求；其原生策略按账号与模型目录条件选择 `gpt-5.6-luna` 或当前模型。Bridge 直接连接 daemon，没有这段触发。原有合成标题用例仅接受首条消息预览并人工注入名称事件，不能证明模型命名发生。本次用户明确要求 Bridge 的自动命名统一使用 `gpt-6-luna`，覆盖最初沿用的原生模型选择策略。

Bridge 新建且标题为空的本机 CLI、独立配置、SSH 与 WSL 聊天，在首条显式消息的原生发送成功后异步命名。排队消息在真正发送时触发。创建或发送重试复用同一资格和任务；未知首条发送不触发，也不让后续消息补触发。已有聊天、被动阅读和通知不登记或启动命名。恢复快捷入口创建的新 CLI 聊天使用同样的空标题规则。

纯附件首条消息只以附件文件名作为命名文本，不传文件路径、图片或内容。后续正常消息不取消仍在生成的首条标题。即使命名取消回执保存失败，主发送回执中更早的 accepted/unknown 仍禁止把后续消息当成首条重新命名。

## 共用模块与原生操作

`features/sessions/auto_titles.py` 管理资格、有限后台队列、固定任务 ID、阶段回执与取消。`clients/codex/title_generation.py` 通过已核验的原连接执行固定的临时结构化请求。主服务、CLI 与 WSL 只适配当前接入的连接、身份、事件和操作门锁；平台模块不承载命名业务。

命名在同一运行时创建 `ephemeral=true`、`threadSource=thread_title` 的临时线程，固定使用 `gpt-6-luna` 模型及 `low` 推理强度，沿用原账号、提供商和工作目录。该选择不依赖账号类型、模型目录或主聊天当前模型；运行时或上游不支持 `gpt-6-luna`、`low` 或结构化输出时，本次命名失败，不回退其他模型，不切换账号或提供商，也不影响主聊天发送和回复。临时线程禁用工具、MCP、Skill、插件、hooks、记忆、终端和外部环境访问，采用原生临时请求的只读或受管权限约束。无法核验配置时终止命名。

输出必须是唯一 `title` 字段的 JSON，标题不超过 36 字。读取线程将已登记临时线程的事件交给独立接收器；这些线程不进入聊天正文、LiveSession、审批或通知。仅接受同一临时任务的完整模型回复与成功完成事件。意外工具或审批请求拒绝并结束临时任务。

## 身份、回执与并发

原生发送和命名绑定原 process/transport 或 WSL server/generation、源线程连接 token、原目录与 provider。实际写入锁内再次检查绑定身份；命名不启动 daemon、不恢复原聊天。回写前重新读取原生名称，Bridge 内手动改名与自动回写共用操作锁，名称事件取消旧候选，自身回写事件不会取消自身。

回执 `auto-titles.json` 不复制消息正文或凭据，只保存任务与提交 ID、接入身份、已知临时 ID、候选标题及状态。生成和回写前先持久化状态；重启后在途任务标记未知，不重复请求。存储失败、模型拒绝或命名失败均不改变主消息的 accepted 状态。关闭、断连和释放取消命名，清理仅作用于已知临时线程及其原连接。

原生 `thread/name/set` 没有条件写入或版本参数。即时重读和名称 revision 保护正常并发及 Bridge 内手动改名；外部 CLI 在最后一次读取与写入之间同时改名，仍有无法用现有协议完全消除的竞争窗口。

## 验证范围

新增任务、协议与完整 Bridge 创建/发送回归，使用合成原生 I/O 验证模型生成与名称写回，而非人工提供标题事件。覆盖主回复仍在运行、本机/独立/SSH/WSL 隔离、排队与重复提交、恢复入口、人工改名、未知发送/回写、原连接变化、临时任务隔离及进程崩溃恢复。旧原生名称同步用例明确使用不支持临时配置的旧运行时，保留兼容验证。
